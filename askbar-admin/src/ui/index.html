Settings

        

          
System prompt

          
Sent with every message. It is never shown to clients.

          
          
Reply time limit

          
A reply still running after this long is stopped and the text so far is kept. The default is 300 seconds (5 minutes); allowed 30 to 3600. A message that waits in the queue is timed from when it starts.

          
          

          
Kill switch

          
Switched on, the server starts no new replies and clears the messages waiting in queues. Clients see a clear message.

          
          
          
Audit

          
How long the audit records are kept before they are deleted (7 days at least, always; the audit database itself refuses to delete anything younger).

          
          
Sealing key: none

          
Display defaults

          
Clients use these unless their own client.yaml overrides them.

          
          
          
          
          
          
          

          

        

        

          
Rotate the audit key

          
Makes a new key from a new passphrase; the server seals everything from then on with it. Content sealed before stays sealed with the old key, and still needs the old passphrase to open. Neither passphrase can be recovered.
