A restore is for the start of a new install: it replaces the server's data and this admin's own with the backup's, and it is refused once anything has been set up here (a provider, a person, an API key or the audit passphrase). It needs a sign-in within the last 10 minutes.

Choose the .tar file you downloaded from the Backup page. It is checked first (which release made it, and that no part is damaged) and a backup from a newer release is refused before the passphrase is asked for. Then enter the backup passphrase, the one that was set when the backup key was made: it opens the backup here and is never stored.
