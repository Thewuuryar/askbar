Download an encrypted backup: one .tar file with the server's data (settings, paired clients and every space's conversations) and this admin's own (its database, its secret keys and the install's certificate). Each part is encrypted so that only your backup passphrase opens it: this admin cannot read it, and it holds everything one restore needs, secrets included.

The file holds manifest.json (which release made it and what is in it), backup-key.age (the private key, protected by your passphrase) and the encrypted parts. With the file and the passphrase, the age tool opens it; the guide says how. The auditor's store is in it too (audit.age, last). Without a backup passphrase set, nothing can be backed up.

To put a backup back, see Restore: it is for a new, empty install.
