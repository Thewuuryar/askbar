Set up Askbar

1. Choose an admin password

This protects this admin site. At least 10 characters.

2. Create the master key

The master key encrypts the provider API keys you store here. The server generates it and keeps a copy in its secrets volume.

You will see it once, on the next screen, so you can save it.

Save your master key

Store it in a password manager (Bitwarden, 1Password, KeePass or similar) now. It is shown only this once.

If the secrets volume is ever lost, this key lets you restore it (choose "I already have a master key" on a fresh install). Without it, stored provider keys must be entered again; conversations are not affected.

Master key

Rotating creates a new master key, re-encrypts every stored provider key (and the Cloudflare token) under it, and shows the new key once. Do this if you think the old key leaked.

Save the new master key in your password manager, replacing the old entry. It is shown only this once.

The server still keeps the previous key as master.key.prev on its secrets volume. Delete it once the new key is saved.
