# Admin actions

What was changed in this admin, and when. Every change an administrator makes, in the admin site or with an admin API key, is recorded in the auditor before it is made, and a change is refused when the auditor cannot take its record. Signing in and out is not recorded. This page cannot list the records yet, because the admin cannot read them back, so its table is shown greyed; see [The auditor](../../guide.md#the-auditor) for what is recorded.
