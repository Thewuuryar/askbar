# Services

Restart a part of Askbar. This page shows whether the server, `model-gateway`, the alerter, the egress proxy, the admin, Caddy and CLIProxyAPI answer, and lets a signed-in person restart each one. The guide explains what each restart interrupts: [Starting and stopping services](../../guide.md#starting-and-stopping-services).

## Running services

Restart a part of Askbar. The list shows each service and whether it is running.
